# Branded order emails (DECISIONS 292)

Six files: three emails × English (the template) and Arabic (its translation). Generated by
`tools/notifications/build.mjs`; change the copy or design there and run `node notifications/build.mjs --preview`
(from `tools/`, with the local preview running for the sample photos), never by hand in these files.

| Email | Shopify admin → Settings → Notifications → | English file | Arabic file |
|---|---|---|---|
| Order confirmation | Order confirmation | `order-confirmation.en.liquid` | `order-confirmation.ar.liquid` |
| Shipping confirmation | Shipping confirmation | `shipping-confirmation.en.liquid` | `shipping-confirmation.ar.liquid` |
| Delivered | Delivered | `delivered.en.liquid` | `delivered.ar.liquid` |

## Install (owner's step; nothing here changes the store)
1. **Logo:** Settings → Notifications → Customize email templates → upload `bts-email-logo.png` (this folder; the
   official wordmark, unchanged), width 120 px. Without a logo the emails show the name as text.
2. **English:** open each email above → Edit code → replace everything with the `.en.liquid` file → **Preview** →
   Save. Suggested subjects:
   - Order confirmation: `We've got your order {{ order_name }}`
   - Shipping confirmation: `Your order {{ order_name }} is on its way`
   - Delivered: `Your order {{ order_name }} has arrived`
3. **Arabic:** add each `.ar.liquid` file as that email's Arabic translation (Settings → Languages → Arabic →
   Translate → Notifications, or Shopify's free Translate & Adapt app). Customers who shop in Arabic get it.
   Subjects: `استلمنا طلبك {{ order_name }}` · `طلبك {{ order_name }} في الطريق` · `طلبك {{ order_name }} وصل`
4. **Test:** "Send test email" on each template, read it on a phone (Gmail and Apple Mail), then place a real test order.

## What's in them
- Brand: white page, the four step colours as a thin band top and bottom, Antonio titles, Figtree text (Alexandria in
  Arabic). Apple Mail / iPhone show the brand fonts; Gmail shows Arial (Tahoma in Arabic).
- Order confirmation: items with photos, subtotal / discount / shipping / total, a cash-on-delivery reminder when the
  order is COD, the delivery address, "How to start" (morning and evening order, sunscreen last), help by reply.
- Shipping confirmation: "Track your order" (the carrier's link, or the order page), what's in the parcel, the COD
  reminder while payment is pending, "How to start".
- Delivered: "How to start" first, then the items, and a button to the account page (routine and reorders).
- No delivery-date promises, no new claims: the routine order is the FAQ's, the step names are the site's.
- Arabic: right-to-left, order numbers and amounts kept left-to-right, gender-neutral Egyptian Arabic.
